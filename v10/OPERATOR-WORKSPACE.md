# v10.x Operator Workspace

Status: Draft
Date: 2026-04-27

## Goal

Consolidate all operator entry points into one unified CLI.

## Commands

- `status` — runtime status snapshot
- `dashboard` — full decision dashboard
- `smoke` — smoke test
- `usage` — usage report
- `trials` — trial registry
- `registry-search` — search trials by assessment or tag
- `benchmark` — run benchmark comparison
