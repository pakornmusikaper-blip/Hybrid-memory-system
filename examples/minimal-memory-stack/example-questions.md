# Example Questions

These questions help validate whether the memory system is working.

## Fact-oriented
- Who is the user
- What was the key decision about the system
- What project is currently active

## Synthesis-oriented
- Why was this architecture chosen
- What is the difference between structured memory and wiki pages
- What should be promoted from notes into the knowledge base

## Troubleshooting-oriented
- What issue was observed
- What was concluded
- What should be checked next time
