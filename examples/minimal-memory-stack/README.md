# Minimal Memory Stack Example

This example shows the smallest useful version of the hybrid memory architecture.

## Layout

```text
minimal-memory-stack/
├── sources/
├── structured/
├── wiki/
└── search/
```

## Purpose

Use this example to show future users how to start small before adopting the full package.

## Adoption Pattern

1. Add 1-3 raw sources
2. Create 2-5 structured records
3. Create 1-3 wiki pages
4. Add a basic corpus manifest
5. Test real questions against the stack
