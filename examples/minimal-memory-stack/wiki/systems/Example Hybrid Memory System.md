## Summary

This example system separates raw evidence, structured facts, synthesized knowledge, and retrieval support.

## Key Facts

- Sources remain immutable.
- Structured records store stable facts.
- Wiki pages store reusable explanations.
- Search artifacts help retrieval but are not source of truth.
