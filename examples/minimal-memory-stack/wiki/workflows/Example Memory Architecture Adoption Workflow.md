## Summary

Adopt the architecture gradually by creating structure first, then records, then wiki pages.

## Key Facts

- Start with folders and templates.
- Seed a small number of structured records.
- Add a few strong wiki pages.
- Test real queries before scaling.

## Notes

Gradual adoption lowers risk and keeps the package understandable.
