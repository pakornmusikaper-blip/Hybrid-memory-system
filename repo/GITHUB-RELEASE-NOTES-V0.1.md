## Title

Hybrid Memory System v0.1, Documentation-First Release

## Release notes body

Hybrid Memory System v0.1 is the first public release of a documentation-first hybrid memory architecture for long-running AI agents.

### What is in this release

- architecture and design guidance
- schema packs for structured records and wiki pages
- category-specific schema guidance
- category-specific templates
- lint and quality standards
- onboarding and quick-start docs
- public-safe examples
- repository and release-structure guidance

### What this project is for

This project is for agent builders who want a more durable alternative to transcript-only memory and a more structured alternative to retrieval-only memory.

### What is intentionally not in v0.1

- heavy automation
- platform-specific runtime integration
- mandatory indexing stack
- opinionated deployment tooling

### Release philosophy

The first release focuses on strong ideas, usable structure, and practical documentation before adding heavy tooling.
