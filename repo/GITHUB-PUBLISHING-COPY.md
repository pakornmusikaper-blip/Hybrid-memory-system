## README opening copy option

Hybrid Memory System is a documentation-first architecture kit for long-running AI agents.

It helps agents move beyond transcript-only recall by separating raw evidence, structured facts, reusable synthesis, and retrieval support into distinct layers.

The result is a memory system that is easier to maintain, easier to review, and more reliable to use across repeated real work.

## Release announcement copy

Hybrid Memory System v0.1 is the first public documentation-first release of a reusable memory architecture for long-running AI agents.

This release focuses on clear architecture, schema guidance, category templates, lint and quality rules, onboarding material, and public-safe examples.

It is designed for people who want a practical way to move from transcript-heavy agent memory toward a more durable and maintainable knowledge system.

## One-paragraph project pitch

Hybrid Memory System combines structured records, wiki-style synthesis, and retrieval support into a single operational memory model for long-running AI agents. Instead of treating all memory as undifferentiated chat history or all retrieval as search, it separates evidence, canonical facts, reusable explanations, and search artifacts into distinct layers with promotion and review discipline.
