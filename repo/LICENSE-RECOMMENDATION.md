# Recommended License for v0.1

Status: Ready to use
Date: 2026-04-27

## Recommendation

**MIT License**

## Why MIT for this project

1. Permissive and broadly understood
   - Developers immediately recognize it
   - Low barrier to reuse

2. Matches documentation-first posture
   - No code-heavy restrictions
   - Attribution + license notice is enough

3. Leaves room for future evolution
   - Can upgrade to a more specific license later if the project evolves
   - Does not lock you in

## Alternative options

### Apache 2.0
- Stronger patent protection
- Good if the project grows into a tool or library with code
- More boilerplate

### BSD 3-Clause
- Similar to MIT
- Slightly more explicit about no endorsement usage
- Also fine

### Unlicense
- Public domain dedication
- Maximum reuse freedom
- May feel too permissive for some audiences

## What to do now

1. Create `LICENSE` in the repo root with MIT text
2. Add to `.gitignore` if you want to keep it local-only before publish
