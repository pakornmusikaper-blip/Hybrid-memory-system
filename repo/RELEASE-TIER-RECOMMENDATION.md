# Release Tier Recommendation

Status: Draft
Date: 2026-04-26

## Recommended current tier

Tier 1, Documentation release.

## Why Tier 1 is the right current release

Because the package already has strong:
- conceptual clarity
- schema guidance
- templates
- examples
- lint and quality management
- onboarding support

A tooling-heavy release is not necessary yet.

## Upgrade path

### Next release tier after v0.1
Tier 2, Workflow release.

Potential additions:
- more adoption stories
- more workflow references
- stronger real-world usage examples

### Later release tier
Tier 3, Tooling release.

Potential additions:
- indexing helpers
- lint scripts
- optional automation

## Core message

Release the strong ideas first. Add tools only when they clearly improve adoption.
