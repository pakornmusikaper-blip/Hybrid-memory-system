# Consistency Checklist

Status: Draft
Date: 2026-04-26

Use this checklist before release or major revision.

## Naming
- [ ] pack names are consistent
- [ ] schema file names are consistent
- [ ] template file names are consistent
- [ ] example file names are understandable

## Structure
- [ ] directory purposes are clear
- [ ] no section duplicates another without reason
- [ ] package index reflects reality

## Quality
- [ ] docs do not contradict each other
- [ ] examples align with schemas
- [ ] templates align with schemas
- [ ] lint expectations align with quality standards

## Publication
- [ ] package is understandable to a new reader
- [ ] no private context is required to understand the repo
- [ ] no sensitive data remains
