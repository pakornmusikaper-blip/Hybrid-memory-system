# v6.4 Benchmark Matrix

Status: Draft
Date: 2026-04-27

## Goal

Compare local-only, external-only, and hybrid-routed execution.

## Metrics

- estimated token input/output
- estimated cost
- latency class
- fallback usage
- route chosen

## Scenarios

- restricted summary
- urgent reflection
- routine status generation
- low-value cleanup

## Modes

- local-only
- external-only
- hybrid-routed

## Why

This is the experiment that tells us whether external models make the memory architecture more cost-effective or just more expensive.
