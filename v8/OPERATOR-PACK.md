# v8.0 End-to-End Operator Pack

Status: Draft
Date: 2026-04-27

## Goal

Make the substrate easy to operate end-to-end from a small set of commands.

## Deliverables

- quickstart for operator workflow
- one-shot demo bootstrap
- unified status command examples
- usage inspection examples
- persisted memory inspection examples

## Why

A capable system still fails adoption if the operator experience is clumsy.
