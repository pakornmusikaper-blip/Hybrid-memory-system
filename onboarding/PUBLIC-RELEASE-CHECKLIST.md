# Public Release Checklist

Use this checklist before publishing the package to GitHub.

- [ ] No secrets or machine-specific credentials remain
- [ ] No private personal records remain
- [ ] Examples are generic and public-safe
- [ ] Package boundaries are clear
- [ ] Quick start docs are sufficient
- [ ] Schemas and templates are internally consistent
- [ ] Lint and quality docs are present
- [ ] The repo is understandable without private context
