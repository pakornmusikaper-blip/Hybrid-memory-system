# v7.1 Persisted Memory Files

Status: Draft
Date: 2026-04-27

## Goal

Persist belief, concept, and cognition state to disk so operator tools can inspect the actual memory system.

## Files

- `memory/beliefs.json`
- `memory/concepts.json`
- `runtime/cognition.json`

## Why

Until now, operator tools mostly saw runtime and usage. Persisted memory files let operators inspect the actual substrate mind-state.
