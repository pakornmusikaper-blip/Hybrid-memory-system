## Why this pack matters

These templates reduce adoption friction by turning schema guidance into ready-to-use files.

They help users:
- start faster
- stay consistent
- avoid field guesswork
- preserve category clarity

## Suggested use

1. Read the relevant category schema
2. Copy the matching template
3. Fill only the fields that are useful now
4. Expand later as the record matures
