# Hybrid Memory System, Roadmap

Status: Draft
Date: 2026-04-26

## Stage 1. Internal incubation with best

Goal:
- prove the architecture in a real workflow
- refine the schema and promotion rules
- identify missing templates

Deliverables:
- package docs
- example file tree
- example records
- example wiki pages

## Stage 2. Workspace adoption

Goal:
- use the package in Pakorn's OpenClaw workspace
- validate practical query behavior
- track what works and what creates friction

Deliverables:
- seeded records
- seeded wiki pages
- maintenance conventions

## Stage 3. Packaging for reuse

Goal:
- make the system understandable and portable for other users

Deliverables:
- cleaned generic examples
- reusable templates
- installation or adoption guide
- optional skill packaging plan

## Stage 4. Public release

Goal:
- publish to GitHub cleanly
- optionally publish as an agent skill

Possible outputs:
- repository
- skill package
- docs site
- example memory stack

## Open questions

- What minimum metadata should every structured record require
- How much frontmatter should wiki pages carry by default
- Should timelines be flat files, monthly files, or structured records
- When should semantic retrieval be introduced
- What lint rules should exist in v1
