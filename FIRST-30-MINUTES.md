# First 30 Minutes

Status: Draft
Date: 2026-04-26

This guide is for the first half hour of adoption.

## Minute 0-5
Read:
- `PACKAGE-VISION.md`
- `ARCHITECTURE.md`
- `SCHEMA-PACK-V1.md`

## Minute 5-10
Create the minimal folder tree:
- `sources/`
- `structured/`
- `wiki/`
- `search/`

## Minute 10-15
Create one source note and three structured records.

Suggested records:
- a user or actor
- a key decision
- a project or system

## Minute 15-20
Create two wiki pages.

Suggested pages:
- one system page
- one workflow or comparison page

## Minute 20-25
Ask three validation questions:
- what fact does the system know
- what explanation has been preserved
- what should be checked next time

## Minute 25-30
Review quality using:
- `lint/LINT-RULES.md`
- `lint/QUALITY-STANDARDS.md`
- `lint/COMMON-FAILURES.md`

## End state

By the end of 30 minutes, you should have a tiny but real memory system, not just a folder skeleton.
