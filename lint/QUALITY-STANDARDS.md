# Quality Standards

Status: Draft
Date: 2026-04-26

## Goal

Quality standards define what good memory artifacts should look like, beyond formal validity.

## Structured Record Standards

A good structured record should be:
- canonical for its fact
- concise
- evidence-backed
- easy to distinguish from similar records
- useful in future retrieval

A weak structured record is often:
- redundant
- vague
- source-free
- too broad or too trivial

## Wiki Page Standards

A good wiki page should be:
- clearly worth preserving
- more synthetic than a raw note
- linked to related ideas when useful
- readable by both a human and an agent
- focused on one real conceptual or operational purpose

A weak wiki page is often:
- a dump of raw fragments
- repetitive with another page
- too small to justify existence
- missing a clear point

## Source Standards

A good source file should be:
- identifiable
- dated when possible
- immutable after capture
- clearly located in the sources layer

## Retrieval Standards

A good memory system should:
- answer fact questions from structured records
- answer synthesis questions from wiki pages
- preserve evidence in sources
- avoid forcing the agent to search noisy layers first

## Efficiency Standards

The system should prefer:
- one strong canonical record over many duplicates
- a few strong wiki pages over many weak ones
- selective promotion over indiscriminate hoarding
