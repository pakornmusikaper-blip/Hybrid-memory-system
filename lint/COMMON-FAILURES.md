# Common Failures

Status: Draft
Date: 2026-04-26

## 1. Everything becomes a wiki page

Problem:
- retrieval gets noisy
- factual precision drops

Fix:
- move stable facts into structured records
- reserve wiki pages for synthesis

## 2. No canonical record exists

Problem:
- the same fact lives in many places
- future answers become inconsistent

Fix:
- declare one canonical home
- link from other places instead of duplicating

## 3. Sources are missing

Problem:
- trust decreases
- later review becomes difficult

Fix:
- add at least one supporting source reference

## 4. Weak summaries

Problem:
- retrieval may find the right file but the summary does not help understanding

Fix:
- rewrite summaries to state durable meaning and scope

## 5. Over-promotion

Problem:
- the system accumulates low-value noise

Fix:
- leave uncertain or low-value observations ephemeral unless reuse is likely

## 6. Local and global memory are mixed

Problem:
- profile-specific operational noise pollutes shared knowledge

Fix:
- keep local overlays separate
- promote only when reuse value is clear
