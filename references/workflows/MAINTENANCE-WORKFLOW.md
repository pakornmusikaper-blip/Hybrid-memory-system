# Maintenance Workflow

## Goal

Keep the memory system useful over time.

## Review items
- orphan wiki pages
- stale structured records
- missing source references
- duplicate canonical records
- rough notes worth promoting

## Suggested cadence
- light review weekly
- deeper review monthly

## Output destinations
- maintenance/lint-reports/
- maintenance/review-queue/

## Principle

Maintenance should preserve quality, not generate busywork.
