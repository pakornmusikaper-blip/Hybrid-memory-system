# Adoption Workflow

## Goal

Adopt the hybrid memory system without overwhelming the agent or the user.

## Step 1. Create the backbone
- create folders
- create schema docs
- create templates

## Step 2. Seed a few canonical records
- one person record
- one project record
- one decision record
- one system record

## Step 3. Seed a few wiki pages
- one system page
- one workflow page
- one comparison page

## Step 4. Test real questions
Ask factual, synthesis, and troubleshooting questions.

## Step 5. Refine before scaling
Adjust schemas, naming, and page conventions before large migration.

## Step 6. Add maintenance habits
- periodic reviews
- stale content checks
- selective promotion from notes
