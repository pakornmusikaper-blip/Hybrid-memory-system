# Query Strategy

## Fact-first questions
Use this order:
1. structured records
2. curated long-term memory
3. recent notes
4. raw sources

## Synthesis questions
Use this order:
1. wiki pages
2. structured records
3. raw sources

## Troubleshooting questions
Use this order:
1. wiki systems and workflows
2. structured systems and decisions
3. sources and logs

## Core rule

Do not search the noisiest layer first if a higher-signal canonical layer already exists.
